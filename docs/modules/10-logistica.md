# Módulo 10 — Logística

> **Área**: Administrativa
> **Estado**: Pendiente de implementación
> **Implementación actual**: Ninguna

---

## Propósito

Gestionar el proceso de adquisición de bienes y servicios: requerimientos, cotizaciones, órdenes de compra y recepción.

## Alcance conocido

### Procesos principales

- Registro de requerimientos de las áreas.
- Proceso de cotización.
- Elaboración de cuadro comparativo.
- Generación de órdenes de compra y servicio.
- Recepción de bienes y conformidad de servicios.

### Funcionalidades conocidas

- CRUD de requerimientos.
- Solicitud de cotizaciones a proveedores.
- Registro de cotizaciones recibidas.
- Cuadro comparativo de cotizaciones.
- Generación de órdenes de compra/servicio.
- Registro de recepción/conformidad.
- Reportes de adquisiciones.

## Actores

| Actor | Rol en este módulo |
|-------|-------------------|
| Áreas solicitantes | Registro de requerimientos |
| Logística | Gestión de compras |
| Proveedores | Presentación de cotizaciones |
| Almacén | Recepción de bienes |
| Director General | Aprobación de compras mayores |

## Relaciones con otros módulos

| Módulo | Relación |
|--------|----------|
| Almacén | Los bienes adquiridos ingresan a almacén |
| Cuentas por Pagar | Las compras generan obligaciones de pago |
| Planificación y Presupuesto | Las compras consumen presupuesto |
| Contabilidad | Las adquisiciones generan asientos |
| Patrimonio | Los activos fijos adquiridos se registran como patrimonio |

## Aspectos pendientes de definición

- Proceso de aprobación de requerimientos.
- Montos para diferentes tipos de adquisición (compra directa, adjudicación).
- Registro de proveedores (¿módulo separado o integrado?).
- Normativa de contrataciones aplicable.
- Documentos requeridos por tipo de compra.
